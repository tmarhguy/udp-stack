== Architecture

Every lab session is the same loop on one FPGA. Live traffic hits the LAN8720. Payload bytes reach `loopback_echo` without a CPU copy. The reply rebuilds Ethernet, IPv4, and UDP headers with swapped addresses and leaves through the same PHY.

image::udp-datapath.svg[RX path from the RMII PHY through MAC, IPv4, UDP, and echo, then back out,width=800]

=== Hierarchy

Inside `udp_stack_core`: `eth_demux` to `ip_rx` to `udp_rx` to `loopback_echo` to `axis_fifo` to `stack_tx`.

The synthesized top is `top` with `u_mdio`, `u_phy`, `u_mac`, `u_stack`, and `u_seg7`.
