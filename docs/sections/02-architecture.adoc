== Architecture

System overview: what the pieces are, how packets flow in and back out,
and where each piece lives in the tree.

=== The loop

Every lab session runs the same story. The full RX-to-TX arc runs on one FPGA.

[source,text]
----
  HOST IN              STACK                 HOST OUT
  ───────              ─────                 ────────
  UDP datagram    →    RMII RX → MAC    →    UDP reply
  port 50000           IP → UDP → echo       (swapped hdrs)
----

. Wire in. Live traffic hits the on-board *LAN8720* PHY. RMII RX, IPv4
filter, UDP port match — payload bytes reach `loopback_echo` without a
CPU `memcpy`.
. Echo. Cut-through forwarding rebuilds Ethernet + IPv4 + UDP headers
with swapped addresses. Latency instrumentation reports cycle count on
`LED[12]`.
. Wire out. Reply leaves through the same MAC and PHY. `LED[9]` / `LED[10]`
pulse on RX/TX; `LED[13]` / `LED[15]` show link up. The 7-segment and
switch-mirrored LEDs tell you the bitstream is alive before you send a packet.

=== Datapath

[source,text]
----
RMII PHY ──► eth_mac_axis ──► eth_demux ──► ip_rx ──► udp_rx ──► loopback_echo
                                                                    │
                                                              stack_tx ◄──┘
                                                                    │
                                                         eth_mac_axis ──► RMII PHY
----

Inside `udp_stack_core`:

[source,text]
----
eth_demux → ip_rx → udp_rx → loopback_echo → axis_fifo → stack_tx
----
