== Packets, with no processor in the path

This design sends and receives network packets in hardware. It implements Ethernet, IP, and UDP on a Digilent Nexys A7 FPGA board. There is no processor on the data path: the packet is handled as it arrives. A packet sent to port 50000 is echoed. In simulation the payload comes back in 2 clock cycles, which is 20 ns at 100 MHz.
